# 特雷森填字室 · v0.3

纯前端赛马娘填字游戏，适合 GitHub Pages。界面与提示支持简体中文、英文、日语；答案支持英文或片假名。

## 本地试玩

需要 Node.js LTS（本项目使用 Node 24）。无需安装第三方依赖，也不需要 `npm install`。

在 Windows 中双击 `启动游戏.cmd`，浏览器打开 http://localhost:5173/ 。保持启动窗口开启，结束时按 Ctrl+C。若已有上一个版本的预览正在运行，先在原窗口按 Ctrl+C，再重新启动并刷新浏览器。

也可以在项目文件夹中打开终端，运行：

```text
npm.cmd run dev
```

在 macOS/Linux 或其他终端中可以使用 `npm run dev`。Windows PowerShell 使用 `.cmd` 可避免执行策略相关报错。

## 如何选题与游玩

开始页和“更换题目”窗口提供三项选题设置：

1. **题目难度**：入门题组 / 进阶题组，决定角色与线索的难度。
2. **填答语言**：英文 / 片假名，决定写入格子的文字，与界面语言独立。
3. **具体题目**：该题组、填答语言下收录的关卡。

目前收录：

| 关卡 | 题盘 | 提示 |
| --- | --- | --- |
| 入门版 1 · 英文 | 24×24，横纵各11题 | 中文、英文、日语 |
| 进阶版 1 · 英文 | 25×25，横纵各11题 | 中文、英文、日语 |
| 进阶版 1 · 片假名 | 19×20，横纵各11题 | 中文、英文、日语 |

片假名关卡按本次要求归在进阶题组，沿用之前片假名入门题的提示。由于当前入门题组尚无片假名题，选择片假名时会自动切换到进阶题组，并显示说明。

**游玩模式**独立于题目难度：

- **辅助模式**（原简单模式）：整条答对后全部标绿，线索下显示这位角色的中文名、片假名、英文名。名字查询无限次。
- **挑战模式**（原困难模式）：过程中没有绿色、正确计数、勾选或答案展示。全部正确后结束。名字查询每局最多提交3次。

## 查看答案与提前结束（v0.3）

- **辅助模式**：在题盘下方点击“查看当前答案”，每局可查看3道不同题目的答案。弹窗展示当前选中线索的完整填答字符串及中文名、片假名、英文名。答案不会自动填入格子，查看期间计时继续。已查看的答案也会显示在线索下方，但不会因此标绿。
- 重复查看同一道题不再扣次数。用完3次后不能查看新的答案，但仍能回看已查看的答案。切换界面语言或游玩模式不会恢复次数，重开或换题才会恢复。
- **挑战模式**：点击“结束并公布答案”并确认后，计时停止，完整答案填入题盘，横向和纵向线索都显示三语名字。题盘使用浅蓝色表示答案展示，状态为“已结束 · 答案已公布”，与正常通关区分。
- 打开结束确认窗口时仍然计时；取消可继续游戏。确认结束后锁定填写，不能通过切换游玩模式继续该局；可选择重新开始或更换题目。
- 名字查询次数与查看答案次数分别计算，互不占用。

**哪些操作会重新开始？**

| 操作 | 填写内容 | 计时 | 挑战模式查询次数 |
| --- | --- | --- | --- |
| 切换界面/提示语言 | 保留 | 继续 | 保留 |
| 切换游玩模式 | 保留 | 继续 | 保留 |
| 更换题组、填答语言或具体题目并应用 | 清空 | 归零 | 恢复3次 |
| 点击重新开始并确认 | 清空 | 归零 | 恢复3次 |
| 打开选题窗口后取消，或仅应用相同题目 | 保留 | 继续 | 保留 |

从点击开始起计时，全部正确后停止。完成后再切换界面语言，完成用时不变。选择设置与查询窗口打开期间，计时仍然继续。刷新网页会重新开始；目前只记住界面语言偏好，不保存题盘进度。

## 名字查询

顶部“名字查询”打开本地词典。支持中文、英文、片假名、平假名、半角假名和名字片段；英语不区分大小写。结果始终同时列出中文、英文、片假名。

当前独立词典收录80位角色，覆盖三套关卡全部角色，也包含不在本次题盘中的角色。它不是实时官方数据库，可自行补充名字与常用别名。

辅助模式可无限次提交。挑战模式每次提交非空查询消耗1次，没搜到也计入；空查询不扣次数。切到辅助模式可以继续无限查询，但再切回挑战模式，已经消耗的次数不会恢复。切换游玩模式会清除上次查询结果，避免跨模式保留结果界面。更换题目或重新开始才重置次数。

## 输入操作

- 英文：输入完整名字、不加空格；自动转换成大写。
- 片假名：每个字符占一格，小写「ャ」「ィ」「ッ」等保留小写，长音「ー」单独一格；「ガ」「パ」各占一格。
- 片假名可使用日语输入法、输入平假名自动转片假名，或者直接粘贴完整名字。不会自动把罗马字转成假名。
- 点击线索定位，方向键移动；Tab/Shift+Tab 切题；空格/Enter 在交叉格切换方向。
- Backspace 删除当前字，当前格为空时向前退一格并删除；Delete 清空当前格。
- 粘贴从选中格起填入当前答案，超过末尾的内容忽略。
- 辅助模式中，改错已完成答案的一个字时，会重新计算标绿和名字展示。交叉格若仍属于另一条正确答案，会保持绿色。

## 维护关卡

请阅读 `docs/关卡数据格式.md`。关卡清单在 `data/levels/index.json`，每张题盘对应一个独立 JSON；三语提示与答案均在关卡文件中，角色三语名字与别名在 `data/characters.json`。添加关卡通常不需要修改 JavaScript。

```text
npm.cmd run check:data
npm.cmd test
npm.cmd run build
```

校验会检查角色关联、三语文案、坐标、交叉字、额外字串、编号、连通性等；打包前自动校验。发布文件生成在 `dist/`，使用 `npm.cmd run preview` 可检查发布版本（同为端口5173，请先关闭开发预览）。

## GitHub Pages

1. 用 GitHub Desktop 将此文件夹作为仓库，提交并发布至 GitHub。
2. 在 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 推送到 `main` 会自动运行检查、打包和发布；也可在 Actions 中手动运行 **Deploy GitHub Pages**。
4. 如果默认分支不是 `main`，修改 `.github/workflows/pages.yml` 中的监听分支。

所有代码和数据都使用相对路径，可部署到 `https://用户名.github.io/仓库名/`，无需额外后端。查询与判定在浏览器本地执行。

## 主要文件

- `src/main.js`：交互、设置、输入法处理、弹窗和界面更新。
- `src/game.js`：判定、计时会话、查询配额、文本归一化、关卡语义校验。
- `src/catalog.js`：从 JSON 清单加载已启用关卡。
- `src/i18n.js`：完整三语界面文案。
- `data/`：关卡和角色词典。
- `schemas/`、`.vscode/settings.json`：数据格式与编辑器提示。
- `tests/game.test.js`：题盘、三语完整性、输入、模式、计时和查询上限检查。

非官方同人小游戏。角色名字参考 https://umamusume.jp/character ，提示沿用本对话制作的三套题。
